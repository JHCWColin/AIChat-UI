使用指导

欢迎使用 AIChatUI

本则使用引导将指导你使用这个全功能的AI对话前端框架，充分发挥生产力，减少遇到的实际体验问题。

必要配置

• 在开始使用AIUI之前，你需要将自己的apikey，以及对应的服务器url填入“设置 - API配置”中，你同样可以在这里调整最大Token限制，以防止单词使用超过预算金额。

• “设置 - API配置 - 模型列表”支持每行填写一个模型名称。你可以增加、删除或调整顺序；保存后主模型选择器与重试选择器会立即同步。模型列表保存在本机 LocalStorage 中，“恢复默认”只会先恢复编辑框内容，仍需点击保存设置。

• 当前版本已移除云端同步与云端记忆入口，所有聊天与记忆仅保存在本地。

• 在设置的其他位置选择你喜欢的背景图片、亮暗模式以及文字大小。以及默认使用的语音输入模型。（前提是你提供的AI后端要支持语音转文字模型）。

文字对话

• 在模型列表里选择模型（前提是AI后端要支持）进行文字对话。

• 对于AI发出的所有消息，可以使用“复制”功能。对于AI发出的最后一条消息，可以使用“重试”功能。

• 使用“语音转文字”模型进行语音输入，识别到的内容将会在鼠标光标（若存在）处插入，或者在末尾插入，不会影响对话框中已有内容。

上下文压缩

• 在“设置 - 对话设置”中可关闭自动摘要，或选择每 10、15、20 个完整对话轮次生成一份独立摘要。摘要只影响发送给模型的上下文，界面中的原始聊天记录不会被删除或隐藏。

• 在输入框开头输入 /compact，或使用“+ - 压缩上下文”，可以手动压缩自上次压缩结束后至今的完整轮次。/compact 后面的文字会作为本次摘要的额外要求。

• 图片、附件和 AI 生成图片不会发送给上下文压缩助手。摘要模型沿用全局 API Key 与 Base URL，可在对话设置中单独指定。

语音聊天

• 首次使用前，在“设置 - 语音聊天”填写对话模型、Fish Audio API、音色 ID 与科大讯飞流式听写凭据。Fish Audio 固定使用 HTTP TTS，语音识别固定使用科大讯飞。

• 可在语音聊天设置中生成 A/B/C 三组预制语音。桌面协作请求附带截图时，A 组播放后必定随机播放一条 C 组语音。

• 从输入框左侧“+”菜单进入语音聊天。当前文字上下文会自动带入；结束通话后，本次完整的人类/AI轮次会自动拼接回当前对话，随后可继续文字聊天。

桌面协作

• 从输入框左侧“+”菜单或托盘进入桌面协作。主窗口会自动最小化，透明字幕窗口停靠在当前显示器底部。

• 按偏好设置中的全局传图快捷键截取鼠标所在显示器；连续截图只保留最后一张，并在下一次语音输入时发送。

• 语音窗口仅显示当前 AI 回复和当前用户发言；深浅主题跟随主窗口。用户持续沉默时不会主动触发模型。

画布编写

• 在对话框左侧的“+”中选择“Canvas”或者手动在输入框的开头处输入指令/canvas以启动画布。

• 若仅发送/canvas则不会调用AI，只会创建空画布。

• 在启用的canvas的会话中，每一次调用AI都会附带上canvas中的全部内容，AI可通过replace指令修改或增添canvas中的内容。

• canvas内容实时本地更新，不需要手动保存。

示例输入：

/canvas 用html配合第三方库写一个日语转罗马音工具

AI回复会被解析为：

修改了画布代码：canvas[replace]with[253行]。

再次输入：

再加入反向转化的功能

AI可以精准修改canvas中的特定部分代码。

绘画工具

• 在对话框左侧的“+”中选择“图像生成”以进入图像生成模式，你会发现模型列表中的模型变成了图像有关的模型。

• 在提示词中加入宽高比关键词即可指定比例，例如“海边日落 16:9”或“人物头像 4：3”。前面的数字是宽，后面的数字是高；不填写比例时继续使用默认的 1:1。

• 若会话中存在AI生成的图片或你上传的图片，可以通过在“+”中选择“图像编辑”以进入图像编辑模式，调用AI时会走向图像编辑端点，对最近的一张AI生成的图片或你上传的图片进行编辑。

• 在“图像生成”或“图像编辑”模式可以在“+”中选择“退出图像生成模式”以回到正常的对话模式。此时为了减少上下文负载，每次调用AI仅会附带最后一张图片作为附件！

示例输入：

（选择图像生成，进入图像生成模式）画一张海滩图片

AI回复示例：

生成完成 【图片1】

第二次输入：

（选择图像编辑，进入图像编辑模式）把太阳改成月亮

AI回复示例：

生成完成 【图片2】

第三次输入：（此时只有【图片2】会被发送）

（选择退出图像生成模式）你看到的是太阳还是月亮？

AI回复示例：

我只能看到月亮在一片沙滩上空。
